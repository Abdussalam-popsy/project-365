# Three.js Template

React + Vite + TypeScript + Tailwind + Three.js starter.

## Includes

- `three` + `@types/three`
- `@react-three/fiber` — React renderer for Three.js
- `@react-three/drei` — helpers (OrbitControls, Text, Environment, etc.)

## Start

```bash
npm run dev
```

## Understand the code

[Read the expandable file walkthroughs](./lessons.md), starting with `@file: src/App.tsx — explained`. They cover every part of the starter, JSX nesting, geometry/material composition, camera values, Tailwind syntax, and a reusable-component example.

## Tips

- Add `motion` (`npm i motion`) for animation sequences
- Add `dialkit` (`npm i dialkit`) for live parameter tweaking
- `@react-three/drei` has loaders for GLTF, textures, HDR environments
