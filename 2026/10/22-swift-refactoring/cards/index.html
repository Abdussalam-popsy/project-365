Spot the Change

See what changed, say the name out loud, then check. A cheat sheet you test yourself on.

Deck done

4 questions that sort out nearly every card
  1. Is the thing that changed a func or a var?
  2. Is it new, gone, locked or moved?
  3. If a var got locked: does it still change inside the class?
  4. If something moved: did the class it went into already exist?
