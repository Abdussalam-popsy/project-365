    The 6 questions to ask when reading code
    
    
      
  1. Who uses it? Only used inside → Hide method. Outsiders can change what they should only read → Encapsulate field / collection. Never changes after setup → Remove setting method.
    2. 
      
  2. Repeats? Same steps in two places → Extract method.
    3. 
      
  3. Too long? One func doing several jobs → Extract method, one per job.
    4. 
      
  4. Names? Unclear name → Rename method. Expression you have to decode → Introduce explaining variable. Hardcoded value → Add parameter.
    5. 
      
  5. Belongs elsewhere? Uses another class's data → Move method. Vars and funcs that only talk to each other → Extract class. Stuck to one concrete class → Extract interface.
    6. 
      
  6. Pointless? Func no clearer than its body → Inline method.
